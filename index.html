Política de Privacidade

Aplicativo: Prazo Fácil

Versão: 1.0.2+3

Desenvolvedor: LMA Informática

Última atualização: 10 de setembro de 2026

1. INTRODUÇÃO

O aplicativo Prazo Fácil foi desenvolvido para ajudar o usuário a organizar compromissos, prazos e lembretes de forma simples.

Esta Política de Privacidade explica quais informações são utilizadas pelo aplicativo, como elas são armazenadas e quais dados são ou não compartilhados.

O Prazo Fácil foi projetado para funcionar de forma offline, sem necessidade de cadastro, criação de conta ou envio dos dados dos prazos para servidores externos.

2. DADOS ARMAZENADOS PELO APLICATIVO

Para funcionar corretamente, o Prazo Fácil armazena algumas informações diretamente no dispositivo do usuário.

Essas informações podem incluir:

  • título ou descrição do prazo informado pelo usuário;
  • data e horário do prazo;
  • situação do prazo, como concluído ou não concluído;
  • configuração de lembrete antecipado;
  • informações internas necessárias para o funcionamento de recursos de teste e configuração do aplicativo.

O campo de título do prazo é preenchido livremente pelo usuário. O aplicativo não exige que sejam informados nome completo, CPF, telefone, endereço ou outras informações pessoais para cadastrar um prazo.

3. ONDE OS DADOS SÃO ARMAZENADOS

Os dados dos prazos são armazenados localmente no próprio dispositivo, utilizando mecanismos de armazenamento interno do aplicativo.

O Prazo Fácil não possui, na versão atual:

  • cadastro de usuário;
  • login;
  • conta online;
  • sincronização em nuvem;
  • servidor próprio para armazenamento dos prazos;
  • banco de dados online para os dados do usuário.

Consequentemente, os dados cadastrados no aplicativo não são enviados automaticamente para a LMA Informática.

4. COMPARTILHAMENTO DE DADOS

A versão atual do Prazo Fácil não compartilha os dados cadastrados pelo usuário com a LMA Informática ou com terceiros.

O aplicativo também não utiliza, na versão atual:

  • publicidade direcionada;
  • ferramentas de análise comportamental;
  • redes de anúncios;
  • rastreamento de localização;
  • acesso aos contatos;
  • acesso à câmera;
  • acesso ao microfone;
  • acesso a mensagens SMS;
  • acesso a arquivos pessoais para fins de coleta;
  • identificação pessoal do usuário por meio de conta ou cadastro.

5. NOTIFICAÇÕES

O Prazo Fácil pode utilizar notificações locais para lembrar o usuário sobre seus prazos.

Essas notificações são programadas e processadas pelo próprio dispositivo.

Para que os lembretes funcionem corretamente, o aplicativo pode solicitar permissões do Android relacionadas a:

  • envio de notificações;
  • programação de alarmes exatos;
  • funcionamento dos lembretes após a reinicialização do dispositivo.

O conteúdo de uma notificação pode utilizar informações do próprio prazo cadastrado pelo usuário, como seu título e horário.

Essas informações são utilizadas localmente para apresentar o lembrete e não são enviadas para um servidor do Prazo Fácil.

6. FUNCIONAMENTO EM SEGUNDO PLANO

Para que os lembretes possam funcionar mesmo quando o aplicativo não estiver aberto, o Android pode exigir configurações relacionadas ao funcionamento em segundo plano e ao gerenciamento de bateria.

O aplicativo pode orientar o usuário a acessar as configurações do próprio Android para permitir o funcionamento adequado das notificações.

Essas configurações são controladas pelo sistema operacional do dispositivo.

7. DADOS UTILIZADOS PARA RECURSOS INTERNOS

Alguns recursos internos do aplicativo podem armazenar localmente informações técnicas necessárias ao funcionamento, como datas relacionadas ao período de teste e configurações do aplicativo.

Essas informações permanecem no dispositivo e não são transmitidas para a LMA Informática.

8. INTERNET E TRANSMISSÃO DE DADOS

A versão atual do Prazo Fácil foi desenvolvida para funcionamento offline.

O aplicativo não possui, em sua funcionalidade atual, comunicação com servidores para:

  • enviar os prazos cadastrados;
  • sincronizar informações;
  • criar contas;
  • autenticar usuários;
  • fazer backup online;
  • coletar localização;
  • enviar dados pessoais para a LMA Informática.

O funcionamento offline pode mudar em versões futuras. Caso isso aconteça de maneira que altere significativamente o tratamento de dados, esta Política de Privacidade poderá ser atualizada.

9. DADOS PESSOAIS

O Prazo Fácil não exige o fornecimento de dados pessoais para utilização de suas funções básicas.

Entretanto, como o usuário pode escrever livremente o título ou descrição de um prazo, ele deve evitar inserir informações pessoais ou sensíveis desnecessárias nesse campo.

A responsabilidade pelo conteúdo inserido voluntariamente pelo usuário permanece com o próprio usuário.

10. SEGURANÇA

A LMA Informática busca utilizar mecanismos adequados para manter os dados do aplicativo armazenados de forma local e protegida dentro das limitações do sistema operacional e do dispositivo utilizado.

Como os dados são armazenados localmente, a segurança física e lógica do próprio dispositivo também é importante.

Recomenda-se que o usuário utilize os mecanismos de segurança disponíveis no Android, como bloqueio de tela e outras medidas de proteção.

11. EXCLUSÃO DOS DADOS

Como os dados são armazenados localmente, o usuário pode excluir os prazos diretamente pelo aplicativo.

A remoção do aplicativo também pode resultar na remoção dos dados locais associados ao aplicativo, conforme o comportamento do sistema operacional Android e do dispositivo utilizado.

O Prazo Fácil não mantém uma cópia dos prazos em servidores próprios.

12. CRIANÇAS E ADOLESCENTES

O Prazo Fácil não solicita deliberadamente informações pessoais de crianças ou adolescentes.

O aplicativo não exige cadastro, identificação pessoal ou criação de conta para seu funcionamento básico.

13. SERVIÇOS DE TERCEIROS

O aplicativo utiliza bibliotecas e componentes de software necessários para seu funcionamento, especialmente para armazenamento local, formatação de datas, notificações e integração com recursos do sistema operacional.

Esses componentes não significam, por si só, que os dados dos prazos sejam enviados para terceiros.

A LMA Informática procura avaliar as dependências utilizadas pelo aplicativo e manter esta Política de Privacidade compatível com o funcionamento efetivo da versão publicada.

14. ALTERAÇÕES NESTA POLÍTICA DE PRIVACIDADE

Esta Política de Privacidade poderá ser atualizada quando houver alterações no funcionamento do Prazo Fácil, especialmente quando essas alterações modificarem a forma como informações são tratadas.

A versão mais recente deverá indicar a respectiva data de atualização.

Recomenda-se que o usuário consulte periodicamente esta política para verificar eventuais alterações.

15. CONTATO

Caso o usuário tenha dúvidas sobre esta Política de Privacidade ou sobre o tratamento de informações pelo Prazo Fácil, poderá entrar em contato com o desenvolvedor:

16. DECLARAÇÃO FINAL

Na versão 1.0.2+3, o Prazo Fácil foi desenvolvido com foco em funcionamento local e offline.

Os prazos cadastrados permanecem armazenados no dispositivo do usuário e não são enviados automaticamente para servidores da LMA Informática.

Esta política descreve o funcionamento do aplicativo na versão indicada acima e poderá ser atualizada caso novas funcionalidades alterem suas características de privacidade ou tratamento de dados.
